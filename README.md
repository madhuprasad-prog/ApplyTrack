# ApplyTrack

ApplyTrack is a responsive job-search workspace for organizing applications, interviews, recruiter details, follow-ups, and resume versions.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Frontend demo

The app uses React, Vite, Tailwind CSS v4, React Router, Lucide, Recharts, date-fns, and react-hot-toast. Demo records are held in React memory only; changes reset when the page is refreshed. There is no backend, authentication, or persistent file upload in this phase.

Pages include the dashboard, application list and Kanban board, application details, interviews, follow-ups, resume vault, and analytics. Application status, search, filters, sorting, CRUD forms, interview scheduling, and follow-up completion are interactive.
